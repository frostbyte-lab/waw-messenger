# Referensi UI resmi WAW

Referensi desain resmi berasal dari `pasted_content.txt` yang dikirim pengguna pada 8 September 2026. Struktur visual yang harus diikuti adalah header WAW Business, tab berbentuk pill untuk Chat/Panggilan/Status/Fitur/Workspace, permukaan putih di atas latar `#F7F8FA`, aksen hijau-teal, ikon fitur berwarna, daftar chat dengan avatar rounded, FAB, dan bottom navigation.

Implementasi Android menyesuaikan header dan tab WAW terhadap struktur tersebut. Data chat, jumlah unread, dan isi quick access tidak boleh diisi angka atau percakapan palsu; data harus berasal dari WhatsApp Web atau fitur Workspace lokal yang benar-benar tersedia. Karena launcher dimulai dari QR/login polos, komponen WAW baru ditampilkan setelah koneksi resmi berhasil.

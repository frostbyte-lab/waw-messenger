# Audit UI WAW — 8 September 2026

## Temuan dan perbaikan

Audit menemukan beberapa kontrol yang tidak memiliki aksi nyata pada halaman utama: QR, Search, Menu, Panggilan, dan Setelan. Kontrol tersebut dihapus agar tidak ada tombol palsu. Navigasi Chat kini membuka koneksi WhatsApp resmi, sedangkan tombol Update hanya dirender saat release GitHub yang lebih baru ditemukan dan membuka dialog update.

Audit juga menemukan data percakapan contoh pada halaman utama. Data tersebut dihapus. Halaman utama sekarang hanya menampilkan status koneksi WhatsApp resmi dan empty state yang jujur sampai pengguna menghubungkan akun.

Pada layar linked chat, WebView sebelumnya dapat tampil hitam atau membawa style bawaan WhatsApp Web. Latar awal diubah menjadi terang, WebView dipaksa tidak menggunakan dark mode, dan style WAW diterapkan setelah halaman selesai dimuat. Baris daftar percakapan diberi kartu terang, radius, shadow, dan aksen warna bergilir.

Deteksi QR/login diperketat. Header, tab, bottom navigation, dan composer WAW tetap tersembunyi selama halaman belum siap atau indikator scan/login masih ada. UI WAW baru muncul setelah halaman siap dan indikator login tidak lagi ditemukan.

## Status

Perubahan telah divalidasi dengan `git diff --check`. Build APK release dijalankan melalui GitHub Actions setelah perubahan dipush. WhatsApp Web tetap digunakan sebagai koneksi resmi dan tidak ada cookie, token, atau session secret yang diekspor.

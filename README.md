# WAW Workspace Tools

Aplikasi ini sekarang hanya berisi lima kelompok fitur yang diminta:

1. **Remote** — OTP pairing, screen sharing, relay, dan kontrol sentuh opsional.
2. **IP & Lokasi** — diagnostik IP lokal serta lokasi perangkat dengan izin Android.
3. **Scan PDF & Edit Dokumen** — komponen PDF, file manager, editor dokumen, dan ekspor PDF.
4. **Absensi Fingerprint** — autentikasi biometrik dan pencatatan waktu absensi lokal.
5. **Custom Watermark** — logo, field custom, timestamp, lokasi, kompas, dan ekspor PNG.

Messenger/WhatsApp Web, updater lama, backup, kalender, notes/tasks, serta modul lain di luar daftar tersebut telah dihapus dari source aktif. Aplikasi dimulai dari `WorkspaceActivity` dan tidak lagi memuat sistem chat.

Fitur yang baru memiliki engine atau class pendukung tetapi belum memiliki layar UI penuh ditampilkan nonaktif di Workspace Hub, bukan sebagai tombol palsu.
